## Built with

[Astro](https://astro.build/) using the [Astro Cactus](https://github.com/chrismwilliams/astro-theme-cactus) theme, Tailwind CSS, and GitHub Actions deploying to GitHub Pages.

## Run locally

```bash
pnpm install

```
